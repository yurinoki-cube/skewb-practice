# Skewb練習

ページ上部のタブで「TCLL Trainer」「手順表」「FL一覧」「FL Trainer」を切り替えます。サイトを開いたときは TCLL Trainer が表示されます。

## TCLL Trainer

- 操作（スクランブルの部分を1本指で / PC はキー）
  - タップ・左にスワイプ：次のスクランブル（PC は → キー・Space キー）
  - 右にスワイプ：1つ前のスクランブルに戻る（PC は ← キー。直近1回だけ。戻すと「前のスクランブル」にはその1つ前を表示）
  - 下にスワイプ：今の問題を苦手に登録（PC は ↓ キー。X キーでも登録）
  - 上にスワイプ：今の問題を苦手から外す（PC は ↑ キー。どのモードでも外せる。weak モード中は X キーでも外せる）
- 「前のスクランブル」にも、そのときの First Layer の色で下線を引きます。
- weak モード（苦手のみ）では、カウンターの所に苦手に登録したパターンの数を表示します。
- training モード（選択したパターンをすべて1回ずつ）では、持ち替えると同じ状態になるケースも別々に出題します（全部選んだときは 1080 問）。

## iPhone のホーム画面に追加（アプリのように使う）

- Safari でサイトを開き、共有ボタン →「ホーム画面に追加」。ホーム画面のアイコンから開くと、Safari の上下のバーなしで全画面で開きます。
- 設定は index.html の `<head>` の PWA 用のタグと `manifest.json`、アイコンは `image/icon-180.png`（iPhone 用）・`icon-192.png`・`icon-512.png`。
- index.html と同じ場所に manifest.json と image フォルダを置いてください（ローカルのファイルを直接開いた場合は使えません。Web サーバーで公開したときに有効です）。


## 手順表

- 表：CLL（完全1面から・134）、EG2（不完全1面 = Diag から・137）、TCLL（18コーナー × 60センター = 1080）
- 1ケースごとに、上にキューブの状態、下に r / r' / R / R' / B / B' / b / b' の8行の手順を並べます。各枠の中で改行できます。
- CLL・EG2 はコーナー（Solved / Peanut / Pi）ごと、TCLL はコーナーケース（1-1〜4-4）ごとに、上のボタンで切り替えて表示します（ボタンは画面の幅に合わせて改行します）。
- 上部（タイトル・設定・表・コーナーのボタン）は、スクロールしても画面の上に残ります。
- 入力内容はブラウザ（localStorage）に自動保存されます。
- 読み込み・書き出しは、手順表の左上の設定ボタン（歯車）から行います。

### CLL・EG2 のケース

- 「【最新】Skewb手順表_20250215」の CLL・Diag シートから作成し、date.js の `CLL_CASES`・`EG2_CASES` に入れています。
  名前は「コーナー（＋位置）/ センター」（例: `Peanut FR / O-perm (cw)`）。
- 状態は、シートの手順の逆手順から作り、solver.js でセットアップ（L R B U）を求めて確認しています。
  図はセットアップのあとに持ち替え（x y z）をして、First Layer を D 面（黄）に表示します。
- シートの手順の記号：上段の角 = R（右）・B（奥）・L（左）・F（手前）、下段の角 = r・b・l・f（UFR の角を手前に向けた持ち方）。z・x・y は通常の持ち替え。
- 注記のあるケース
  - 「全パターンから補完（要確認）」… シートの手順では状態が作れなかったセル（CLL: `Peanut BL / O-perm (ccw)`・`Pi BR / Wat (cw/1oppleft)`）。
  - CLL の Peanut・Pi の U-perm は `U-perm(FR-cw)` のように「動く3つのセンターのうち、対面色が入っている面（oop）＋回る向き（cw / ccw）」で表す（`U-perm(FR-cw)` = シートの U-perm (FRr)）。Solved の Z-perm・U-perm は位置を付けない。
  - EG2 の Solved は Z-perm（side は向きを変えると front と同じ形なので1つ）→ Pure → H-perm → U-perm(cw) → U-perm(ccw) の順。Pure と H-perm は持ち替えで同じ形になるが、持ち替えにくいので別ケースとして扱う。
  - EG2 の Peanut・Pi の U-perm は `U-perm(cw)-BR` のように「向き（Solved の U-perm(cw)/(ccw) と同じ形か）＋ oop の面」で表す。EG2 の oop は、センターがその面の下2つのコーナーのステッカー色のどちらとも違い、かつ下のコーナーのどちらかに、センターの対面色が含まれている面。並びは cw → ccw、FR → FL → BL → BR。
  - EG2 でシートに無い14ケース（Peanut 7・Pi 7、すべて U-perm）は全パターンの列挙から追加（注記なし）。
  - EG2 の図とセットアップは、正面のコーナー（UFR）が白・赤・緑になる色の付け方にそろえている。

### TCLL の状態の図

- `buildTcllState`（scramble.js）で状態を作り、solver.js で求めたセットアップから図を描きます（First Layer は D 面）。

### 一括編集（読み込み・書き出し）

- **CSV書き出し**：表示中の表を全ケース分（空欄も含む）書き出します。Excel 等で編集して読み込めます。
- **JSON書き出し**：すべての表をまとめて書き出します（バックアップ用）。
- **読み込み**：CSV / TSV / JSON に対応。列があるものだけ書き換えます（空欄の列はその手順を消します）。

CSV の列（1行目は見出し）：

```
sheet,id,name,setup,r,r',R,R',B,B',b,b'
```

- `id`（必須）：ケースの名前（初期の名前）。CLL・EG2 は `Peanut FR / O-perm (cw)`、TCLL は `1-1 Pure` や `3-2 Ur-fr`
- `sheet`：`CLL` / `EG2` / `TCLL`（省略すると表示中の表）
- `name`：表示名を変えるとき
- `setup`：CLL・EG2 の状態のセットアップ（参考。読み込みでは使いません）
- 枠の中の改行は、`"` で囲んだセルの中の改行で表します。

## FL一覧（一面の手順）

- 一面は FL 面（このツールの色の配列では F 面＝緑のセンター）に作ります。手順は r, r', R, R', B, B', b, b' の8種類（手順表と同じ記号。どれも FL 面のセンターを動かさない）。
- 状態の図は一面を D 面にして（持ち替え x'）、一面の色を紺（#223A70）、それ以外をライトグレー（#D3D3D3）で描きます。
- パターンは、一面に正しい向きで揃っているコーナーの数と位置で分けます：Triangle（3個）・Block（隣り合う2個）・Arrow（対角の2個）・Line（1個）・Done（0個）。
- 紺の見え方が同じものは1パターン。FL 面を軸に 90° ずつ回して（z）同じ形になるものもまとめています（Triangle 8・Block 64・Arrow 21・Line 296・Done 351、計740）。
- 図の向き：揃っているコーナーがなるべく奥（図の D 面の上側）に来る向き。ただし Block は、そこから FL 面を軸に 90° 回した向き（Block 1 が r' R' で揃う向き）にしています。
- 1パターンに2列：左が完全一面（コーナーの側面が揃う）、右が不完全一面（対角の2つのコーナーが入れ替わり、側面が対面色）。
  - 同じ紺の見え方でも、コーナーの側面の色によって完全／不完全が入れ替わるため、見本の状態（揃った状態から「セットアップ」を回した状態）を基準にしています。見本は、完全一面までの手数が短い方を選んでいます。
- 載せる手順（列ごと）：5手以下はすべて。最短が5手の列は6手まで、6手の列は7手まで、7手の列は7手だけ。
  例外として、5手以下が1手順しかない列は6手まで載せます。
  同じ角を続けて回す手順（R R など）と、途中で一度その一面が揃ってしまう手順は載せません。
- 一覧の表示：5手以下の手順と、お気に入りにした6手・7手（お気に入りは太字。同じ手数の中で上に表示）。5手以下が無い列は「○手（図をタップ）」と表示します。
- 詳細画面：図をタップ／クリックすると開きます。開いたときに6手・7手を計算して、載せる手順をすべて表示します。
  各手順のチェックでお気に入りを選べます（ブラウザの localStorage に保存）。
- データ：5手以下の手順だけを前もって計算して date.js の `FL_PATTERNS` に入れています（1手 = 1文字の番号 0=r 1=r' 2=R 3=R' 4=B 5=B' 6=b 7=b'。各列に最短手数と、6手・7手を含めた手順の数も入れています）。
  6手・7手は、FL 面の4つのコーナーの状態（11664通り）をすべてたどる表を作って求めます（algsheet.js の `getFlEngine`・`findFlLongAlgs`。最初に詳細画面を開いたときに一度だけ表を作ります）。r R B b の動きは date.js の `FL_MOVE_PERMS`。

## FL Trainer

- FL一覧のパターンの、一面の手順のあとの CLL・EG2 を読む練習用。画面・操作（タップ・スワイプ・矢印キー・training・weak・カウンター）は TCLL Trainer と同じです。
  TCLL Trainer とは、training・weak モード・苦手（`fl-trainer-weak`、FL パターンごと）・カウンター・スクランブルの履歴を別々に持ちます。
- 練習の流れ
  1. FL選択画面（箱のボタン）で、練習したい FL一覧のパターンを選ぶ（グループごとに All / Clear、全部選択 / 全部解除。選択はブラウザに保存）。
  2. スクランブルでキューブを崩すか、図を見て、一面の手順を回したあとの CLL・EG2 を読む。
  3. 図の下の一面の手順（左の列が完全一面、右の列が不完全一面。表には列の名前は書いていません）をタップすると、回したあとの LL の状態（一面が D 面）と CLL・EG2 の名前をモーダルで表示する。
  4. 確認できたら次へ。苦手と感じたら苦手に登録（下にスワイプ / ↓ キー）。
- 一面を作る色のボタン（図の下。白・黄・緑・青・赤・オレンジ）：押すと、その色の一面の FL一覧のパターンと、その向き（FL一覧の図と同じ向き）の図・手順に切り替わります。
  最初は出題したパターンの色。同じ紺の見え方でもコーナーの側面の色で完全／不完全が入れ替わるときは、FL一覧の不完全一面の手順を左（完全一面）に表示します。
  その色の一面がもう揃っているときは「揃っています」と表示し、「LL の状態を見る」をタップすると今の CLL・EG2 をモーダルで表示します。苦手に登録するのは、出題したパターンです。
- 載せる手順：5手以下と、FL一覧でお気に入りにした6手・7手の中から、お気に入り → 短い手順 の順に、1列3つまで。
  表の大きさは固定（1列 = 5手の手順が入る幅 × 3行。足りない行は空けます。お気に入りの6手・7手は文字を小さくして幅に入れます）。載せる手順が無い列は、最短の手数（「6手」など）だけ表示します。
  パターン名をタップすると FL一覧の詳細画面を開きます（そこでお気に入りにすると、閉じたときに一覧に載ります）。
- 問題の作り方（scramble.js の `buildFlTrainerState`）：揃った一面に CLL のケース（または全部揃った状態）をランダムに選んで FL 面を軸にランダムに回し、FL一覧の見本のセットアップを回す。一面の色もランダム。
  スクランブルは、その状態を solver.js で解いて求めます（`solveColorsForScramble`。色の配列を solver.js の状態に変換）。
  色ごとの一面のパターンは `getFlView`（一面の色のステッカーの位置で FL一覧のパターンを探し、見本と色の付け替えで一致するかで完全／不完全の向きを決める）。
- 画面の並び（FL Trainer だけ）：上から スクランブル → 手順の表 → 色のボタン → キューブの状態。スマホで親指が届くように、キューブの状態を下の方に置いています。
  キューブの状態の部分（`touchArea2`）でも、タップ・スワイプの操作はスクランブルの部分と同じです。TCLL Trainer の並びは元のまま（main.js の `switchTrainer` で canvas を移します）。
- 図：キャンバスの高さを図に合わせています（間隔は main.css の `#view-trainer.flt-mode #canvas` と `.flt-colors`）。「First LayerをD面に表示する」がオンのときは FL一覧と同じ向き（選んだ色の一面が D 面。手順の r R B b をそのまま回せる向き）、オフのときはスクランブルを回した向き。
- 設定（FL Trainer のときだけ表示）
  - 「LLコーナーを非表示にする」（選んだ色を含まないコーナー）・「LLセンターを非表示にする」（選んだ色以外のセンター）。非表示はライトグレー（#D3D3D3）。
  - 「Doneを除く」（初期値オン）：一面が Done のパターンになる色のボタンを出さない（選んでいる色は出す）。
    オンのときは、FL選択画面の Done は非選択で固定（タップ・All・全部選択でも選べない。出題もしない）。Done の選択の記録は残り、オフにすると戻ります。
- 手順を回したあとの CLL・EG2 は、一面を D 面にした状態を、D 面を軸にした持ち替えと色の付け替えでそろえて、手順表の CLL・EG2 のケースと比べて決めます（`findLlCase`）。
  コーナーが全部揃っているときは、ほかの面を一面として見たケースも探します（例：縦の U-perm = 一面の向きを変えた Solved / U-perm）。

## 設定（TCLL Trainer・FL Trainer 共通）

- 「前のスクランブルを表示する」：トレーナーごとに設定（初期値は TCLL Trainer がオン、FL Trainer がオフ）。オンのとき、最初のスクランブルでは「前のスクランブル : 」だけ表示します。
